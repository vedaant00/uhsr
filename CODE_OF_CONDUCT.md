## 🌈 Overview
To foster an inclusive and welcoming environment for all contributors, add a `CODE_OF_CONDUCT.md` file to the repository.

This will ensure contributors know what behaviors are expected and how to report unacceptable behavior. It also aligns with Hacktoberfest’s guidelines for healthy open source communities.

## 🧩 What to Include
Use the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as the base template and adapt it for this project.

Key sections:
- Our Pledge
- Our Standards
- Enforcement Responsibilities
- Scope
- Enforcement Guidelines
- Attribution

## ✅ Acceptance Criteria
- [ ] Create a new file named `CODE_OF_CONDUCT.md` in the root directory  
- [ ] Use the Contributor Covenant v2.1 text  
- [ ] Add a “Contact method” (e.g., GitHub issue or project email) for reporting violations  
- [ ] Ensure formatting and section headings are clear

## 💡 Additional Context
Adding a code of conduct demonstrates that this project values inclusivity and respectful collaboration. It’s also an important part of Hacktoberfest best practices.
