## 🧭 Overview
To make it easier for new contributors to get started, we should add a `CONTRIBUTING.md` file to the root of the repository.

This file should describe:
- How to set up the project locally
- Branch naming conventions
- Code style / formatting rules
- How to open pull requests
- How issues are triaged and reviewed
- How to communicate and ask questions

## ✅ Acceptance Criteria
- [ ] Create a `CONTRIBUTING.md` file in the root directory
- [ ] Include setup and contribution guidelines
- [ ] Mention how to run the project locally
- [ ] Add basic PR and review process
- [ ] Reference linting tools (if any)
- [ ] Make it clear, beginner-friendly, and concise

## 💡 Additional Context
This will help contributors participate confidently during **Hacktoberfest** and reduce confusion around setup and PR submissions.
